01 — The problem

Insight and execution live in different rooms.

Think9 runs 11 brands today under one philosophy — Insights → Strategy → Design → Execution — scaling toward 30+. In practice, a trending ingredient, a competitor's price cut, a celebrity partner's buzz spike has no automatic path to a content brief, a draft, a compliance check, and a shipped asset. Someone has to notice, decide, and manually route it. That latency is the bottleneck.

Today

Manual handoff

Research and content are separate motions, separate teams, separate cadences.

Today

No compliance memory

The same brand-tone mistake gets caught, and re-made, over and over.

Today

No portfolio view

Brands that share a consumer or a distribution channel don't know it.

02 — The thesis

Automate the noticing, drafting, and checking. Keep every decision human.

PULSE collapses "a signal exists" into "brand-safe, human-approved content exists" — one traceable, visibly-looping pipeline, replicable identically across every brand in the portfolio.

03 — The signal-to-shelf loop

One contract, any source.

A trend, an ingredient, a niche creator post, a competitor move, a celebrity spike — every signal becomes the same shape of object before it reaches content. That's what makes this one system, not three tools sharing a UI.

04 — Architecture

A supervisor, three pods, nine agents.

A hierarchical LangGraph — not a flat chain. The Orchestrator routes to independently compiled subgraphs; every pod shares one state contract.

07 — Human-in-the-loop

Agents draft, score, and flag. Humans decide.

  • Content approval — nothing publishes without a click.
  • Celebrity risk — acknowledged or escalated, never auto-acted on.
  • Creator outreach — added by a human, never auto-contacted.
  • Competitor alert — flagged, no auto price-matching.
  • Founder digest — draft until a human publishes it.
  • No code path calls a publishing, payment, or outreach API. Ever.
08 — Honesty policy

Never presents a fallback as live.

Every signal carries a mode field. The UI shows the difference. This matters more than it sounds — a demo dashboard that quietly shows static data as real is the fastest way to lose credibility with a room that builds real products.

Real

News RSS, Reddit, YouTube, Pollinations

No key required. Always attempted live.

Best-effort

Instagram, Scrapfly competitor crawl

Live attempt first, honest fallback tag on failure.

Seeded

11 real brands, celebrity + competitor snapshots

Clearly labeled, never disguised as live.

09 — What's actually running

Not a mockup. Verified, with evidence.

  • Real Google News RSS signals fetched live, per run
  • Full Guardian loop observed live — a genuine fail, revise, re-check cycle
  • interrupt() pause/resume proven standalone before wiring real nodes
  • Real files on disk after every run — drafts, reviews, decision log
  • One real bug found mid-build (a LangGraph reducer duplicating state across pod hops) — caught, root-caused, fixed, re-verified
  • $0 running cost — free-tier data sources, Groq's free LLM tier
